# # Employee & Project Management System

## About the Project

This project is a **MySQL-based Employee & Project Management System** created to practice and demonstrate practical SQL and database management skills.

The system is designed to manage important company information such as employees, departments, projects, salaries, and employee-project assignments. The database is structured using relationships between tables so that information can be stored and analyzed efficiently.

## Project Objectives

The main objectives of this project are to:

- Create and manage a relational database using MySQL
- Store employee, department, and project information
- Establish relationships between tables using Primary and Foreign Keys
- Maintain data accuracy using database constraints
- Perform data analysis using SQL queries
- Create views for reporting
- Generate useful metrics for a mini dashboard

## Database Structure

The project contains four main tables:

- **Departments** – stores department information
- **Employees** – stores employee details, salary, department and manager information
- **Projects** – stores project details and budgets
- **Employee_Project** – connects employees with projects and records project hours

## SQL Concepts Used

During this project, I worked with:

- CREATE, INSERT, UPDATE, DELETE and ALTER
- Primary Keys and Foreign Keys
- NOT NULL, UNIQUE and CHECK constraints
- JOINs
- GROUP BY and HAVING
- Aggregate functions such as COUNT, SUM, AVG, MAX and MIN
- Subqueries
- SQL Views

I also created **Employee Summary, Payroll, and Department Salary views** for easier reporting and analysis.

## Analysis & Dashboard Queries

The project includes queries to find total employees, departments and projects, average/highest/lowest salaries, department salary expenditure, the most active employee, maximum project hours, and the project with the highest budget.
